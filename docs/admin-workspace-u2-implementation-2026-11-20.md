## U2a：客户工作台与全局左侧导航

- 总览独立置顶；六个可折叠分类按客户、商品服务、财务、运营、系统配置、通知运维组织。原 31 个入口完整保留，加总览共 32 个；逐叶子检查原权限，不添加分类级父 Gate。
- 客户详情使用八个普通 URL 页签，先校验页签与所属域权限，再查询当前客户和当前明细。概览不查询七类历史；历史页签不附带钱包与有效服务聚合。每类明细独立每页十条。
- 对象条合并姓名、编号与状态；概览只留账户资料和获授权指标。资料、钱包与更多操作仍调用原 C2/C3 Action，当前页签、分页与单层来源由固定白名单恢复。
- 公共导航支持旧记录锚点／分页到页签的固定映射，纯空 query 保留原 POST 默认返回。其余对象在后续两批逐一接入。
