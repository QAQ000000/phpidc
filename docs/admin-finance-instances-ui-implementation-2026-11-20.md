# 后台账单与实例 UI 推广实施记录

日期：2026-11-20。基线：`f8614f0`。页面合同见 `admin-finance-instances-ui-contract-2026-11-20.md`。

## 交付范围

本批完成财务账单列表、账单核查详情、经典魔方服务列表和单实例详情，复用上一批卡片、筛选条、表格、状态徽章及分页组件。全局 6 个可折叠分类、30 个入口不变；无内部侧栏、分类 Tab 或手机端分类下拉。

### 账单与支付核查

- `/admin/finance` 保留完整账单号精确匹配、客户 ID、账单状态筛选，补充真实账单类型筛选。结果按 ID 倒序，每页 20 条；链接只携带已验证筛选，字符串 `0` 保留筛选意义。
- 行内展示账单/客户、类型/状态、原始总额与币种、钱包/网关分配、创建时间和核查入口。中文业务标签对应现有枚举；商品 Paid 标“已入账”，充值 Paid 标“已到账”，不将付款等同开通。
- `/admin/finance/invoice?invoice_id=ID` 按事实卡片组织客户/商品/服务关联、支付与到期时间、金额分配、优惠及预计上游成本。保留关联流水、任务和只读续费恢复链。
- 支付尝试与回调分别使用安全字段表格、独立 10 条分页；翻页保留当前账单、另一表页码及安全的列表返回条件。请求载荷、回调原文、签名、密钥和加密订单不进入列表或浏览器状态。
- 原退款和钱包充值配置收在各自卡片的可展开操作区。原 Gate、CSRF、POST 路径、原因/确认、保留服务豁免、外部退款完成登记、充值固定范围与禁止充值退款均保持。

### 经典魔方服务

- `/admin/upstream-instances` 改为每页 20 条的稳定倒序表格，支持名称/本地 ID/精确上游主机 ID、连接、服务状态的本地组合筛选。停用连接事实仍可查看，换绑候选继续仅限已启用的经典连接。
- `?instance=ID` 进入当前服务详情，展示客户/商品 ID、绑定、主机名/IP、状态、计费周期/续费金额、到期/最近同步时间及暂停原因。列表不读取实例凭据、令牌、完整配置或任务载荷；详情同样按可见字段裁剪。
- 暂停、恢复、终止和热换绑放在当前实例详情操作区，保留原权限、字段和明确确认。机器命令核对、映射核准路径保持。列表展示全局最近 40 条经典任务，并注明不随实例筛选变化；详情仅展示该实例最近 40 条任务。
- 失败后精确展开原操作区并恢复非秘密字段，不串到其他操作或记录；合法控制请求 ID 保留，确认框仍须重新勾选。非法数组不再导致回填 500。

### 公共布局

支持的长账单号/主机名在手机上暴露了网格最小内容宽度问题。本批限定公共网格列与标题容器宽度，并允许长标题换行，避免内容被面板裁切；未引入新框架或通用表格引擎。
