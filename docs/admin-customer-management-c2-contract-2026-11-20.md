# C2 客户基础管理合同

日期：2026-11-20；基线 `2a5a5c8`。用户验收 C1 后明确批准姓名／邮箱／手机号编辑、管理员发起标准密码重置、独立账户停用／恢复，以及客户详情纯 HTML 锚点快跳。沿用必要迁移、预览部署和自动提交授权；本批不自动推送。

## 数据与权限

新增一条迁移，仅增加 `users.disabled_at`（nullable timestamp）与 `users.auth_revision`（unsigned integer，默认0）。前者是账户访问停用，独立于 `deleted_at/anonymized_at`；后者使文件／Redis／数据库等会话在恢复后也不能复活。停用及实际联系方式变更提升版本并撤销 remember 凭据、既有数据库会话；恢复不回退版本。没有全局 User 查询过滤，不更改资金、服务、角色或历史归属。

新增固定 `customer-operator`：`customers.view`、`customers.manage`、`customers.password-reset`、`customers.status.manage`。日常运营与全部业务预设接入；财务只读继续只有客户查看。C2 Web 写操作同时要求客户查看与对应专权，事务内按 ID 升序锁定操作人和目标并重验状态／权限。

C2 仅管理普通客户；本人、拥有后台角色或直接权限的账户，以及已注销账户不能在此编辑、重置或停用／恢复。管理员身份变更不通过客户管理绕过角色管理权限。角色预设不自动修改既有账号；预览只为完整业务管理员 #3 定向补 customer-operator，#2 保持客户只读，其余账号不变。

## 写操作

- `POST /admin/customers/{customer}/profile`：只接收 name、email、phone 与可选255字备注。姓名必填、最长255；邮箱 trim／小写且采用现有大小写兼容唯一校验及数据库唯一索引，检查保留身份；手机号可清空，非空沿用 E.164 及全身份唯一校验。其他资金、实名、角色、状态字段不能写入。
- 邮箱实际改变时清邮箱验证、删除旧邮箱恢复 token、废弃旧 email/mail 验证绑定；新邮箱不自动验证。手机号改变时废弃旧 SMS 验证绑定／OTP，不自动证明号码归属。相关变更复用现有 phone-binding 缓存互斥后再锁用户，避免已经读走的旧 OTP 穿透；无关 Telegram／OAuth／实名及历史通知不改。联系方式变化撤销旧会话，姓名单独变化不撤销。
- `POST /admin/customers/{customer}/password-reset`：管理员只触发原标准重置链接，不能输入密码、token或收件地址。按目标 ID 锁定并确定当前邮箱后创建 broker 哈希 token，复用60秒节流、可信 app.url、60分钟有效期及事务外发送。审计记录真实管理员及发送结果，不冒充客户；未知发送结果不自动重发。停用／注销／后台账户拒绝重置。完成重置仍复用原身份流程，不自动登录、不验证邮箱。
- `POST /admin/customers/{customer}/access`：显式 disabled 布尔值。停用撤销会话、remember凭据和恢复token，保留身份／余额／账单／服务／角色；恢复只恢复访问许可，不恢复旧会话或旧验证证明。同状态重复提交无重复状态变更。备注默认可选，不要求编造原因。

实际写入与管理审计原子提交，保留请求审计上下文。审计只记变更键、状态、验证失效与发送状态，不保存邮箱／手机明文差异、密码、token或重置链接；沿用审计投影并只为本批明确的键增加白名单。

## 认证与业务准入

密码登录、OAuth／Telegram共有锁内身份、Filament面板准入拒绝停用账户。普通 Web 与 Filament显式栈均校验访问状态和会话版本，Livewire延续相同准入；旧会话退出，恢复后须重新登录。现有零版本会话可兼容，新增登录会话登记当前版本。`/up`、安装、公开页面与无会话的API回调不因停用中间件触发额外安装前数据库依赖。

新的人为购买、充值、续费／升级、续费恢复／钱包分配与新支付尝试在外部请求前及用户锁内检查当前访问状态；保留原已建请求幂等读取与金融锁序。普通请求停用后不能继续进入新业务。已通过准入并提交的外部动作仍按原事实收口，不承诺取消全部在途请求。

原可信自动续费出账、同步、到期暂停与已付款履约继续现行服务合同；支付回调仍按原账单与所有者验签入账。停用不是注销或停服，不新增取消履约、转钱包、退款、清空outbox或重试外部请求的逻辑。

## 页面与验收

客户列表增加独立「已停用」状态筛选与徽章；默认正常不包含停用，注销筛选保留原语义。新状态进入搜索描述，但不扩大搜索查询域。详情在概要后增加资料／服务／账单／流水／工单／实名／通知／审计纯 HTML 锚点，只输出可见区块，无新侧栏、分类Tab或构建链。分页带本区块锚点。

详情表单复用 x-admin.dialog，按专权／目标资格显示，固定 _admin_form＋客户 ID 隔离回填，失败只恢复相应非秘密输入；错误自动重开该弹窗。重置和停用说明影响范围，重置结果不虚称已送达。

验收覆盖新角色与只读403、管理员目标／本人／注销拒绝、唯一性及原子回滚、邮箱验证／旧token／OTP／绑定失效、无明文审计、版本与多会话存储、停用及恢复后的密码/OAuth/后台/Livewire、Action锁前锁内准入、历史回调／已付款履约／自动生命周期保持。允许 C1 精确字段断言仅增加 disabled_at，及原单条 User 查询假设按明确认证/状态变更定向更新；不放松域权限、隐私、金额、身份或幂等断言，不改 Specs。

隔离数据库和模拟邮件／供应商验收桌面／手机明暗主题、锚点／回填／状态操作。共享预览仅备份迁移和已知管理员定向角色部署，不向真实客户发送重置邮件或修改客户资料。完整Pest/PHPStan/Pint及浏览器验收通过后自动提交。
