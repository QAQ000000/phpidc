# 后台库存、清算与运维页面合同（B2）

日期：2026-11-20。基线：`3b75f3e`。用户验收 B1 后确认继续 B2；本批复用 Filament 外壳、`x-admin` 组件及原生 `<dialog>`，不新增迁移、依赖或前端构建链。

## 范围与页面组织

| 页面 | 展示与操作 |
| --- | --- |
| `/admin/inventory` | 本地卡池商品库存概览、实际支持的商品搜索和分页 |
| `/admin/inventory/cards` | 卡密元数据列表、商品/状态/批次筛选；导入表单进入对话框，卡密不回填、不展示或导出 |
| `/admin/fulfillment` | 已付待交付列表；仅原有可重试失败任务提供恢复对话框 |
| `/admin/finance/ledger` | 只读流水、支付回调两张表；保留应收证据有效性与筛选作用范围说明 |
| `/admin/finance/receivables` | 应收列表、选中记录详情、清偿/冲正历史；登记、完整冲正和复核进入独立对话框 |
| `/admin/wallet-clearances` | 钱包结清列表、来源案件、注销身份登记与各阶段原操作对话框 |
| `/admin/external-payouts` | 外部佣金提现状态筛选、列表及各阶段原操作对话框 |
| `/admin/reconciliations` | 案件列表、选中案件的原事实与追加证据；原核查和处置入口整理为对话框 |
| `/admin/tasks` | 全状态履约任务、失败队列元数据两张表；保留业务权限和失败状态限定的重试对话框 |
| `/admin/access` | 账户查找、当前角色列表、固定角色权限说明；批量角色调整进入对话框 |
| `/admin/audit` | 只读审计表与现有精确筛选；复杂快照可展开，沿用白名单投影 |
| `/admin/notification-outbox` | 持久事件、渠道投递两张表；仅待核对投递提供原人工核对对话框 |

保留六个可折叠全局分类、三十个入口，不新增内容侧栏、分类 Tab 或手机分类下拉。列表采用说明/操作区、真实查询支持的 GET 筛选、紧凑语义表格和分页；复杂事实在当前记录详情或可展开区域展示。金额和操作右对齐，状态以文字与徽章共同表达；空表保留表头和明确说明。未知状态保留安全回退，不将未核验等同于无债、无异常或已成功。

## 权限、表单与敏感边界

全部旧 GET/POST 路径、路由绑定、CSRF、原字段、分页与记录参数继续有效，Controller/Action 的 Gate、状态机、幂等、版本、租约和证据要求保持。查看角色不出现写表单，无页面权限保持拒绝；账户不可改本人角色或授予服务器专属权限。普通备注继续可选；退款/冲正、未知出款释放与投递重试等原有确认和真实证据仍须填写，不添加多余确认。

同页对话框使用固定 `_admin_form` 白名单，并同时核对记录/操作标识。失败只重新打开对应表单并恢复允许的输入，不跨记录或跨操作填入旧金额、角色、证据、请求标识。显式 URL 记录优先，已不存在或不适用的操作不借错误回填重新开放。卡密、密码、密钥及全局禁止闪存的输入始终不恢复；收款资料仍只走原有受审计 POST 详情入口，不解密加入 GET/HTML。旧无标记 POST 保留可见错误反馈。

流水、审计和 outbox 沿用现有字段投影；不显示回调原文、队列 payload/exception、通知收件人、加密快照或原始传输异常。所有用户文本和证据转义。只读 GET 与打开/取消弹窗不调用供应商、支付或通知、不新增业务写入；应收原完整核验/预算和进度入口保留。金额直接展示既有定点字符串，不在模板重算。

## B1 小清理

工单无关联服务显示“未关联服务”，状态与列表统一中文；通知日志渠道和投递结果使用中文映射，未知值安全回退。下载外链 URL 校验给出中文字段提示，不借此更改全局语言或业务规则。CMS 的备注在 Web 校验和三个保存 Action 中对齐审计列 255 字符，过长输入明确拒绝且不部分落库；不扩展审计列、不截断证据。具体实现后更新 B1 保留限制的状态说明。

## 视觉与验收

复用统一 Token、13px 基础字号、8px 圆角和公共表格/卡片/徽章/分页/对话框。桌面 1440×1000 与手机 390×844 的浅深色均验收；表格局部横滚、长值局部换行，文档不横向溢出，手机保留必要字段。弹窗不嵌套，具标题、关闭/取消，支持 Escape、焦点返回和内容滚动。

新增有意义的 Feature 回归覆盖权限、旧字段与路径、表单错误隔离、卡密/收款/队列/通知隐私及 CMS 超长备注无写入；不改旧业务断言或 Specs。浏览器使用独立数据库/storage 与模拟对端验收十二入口、明暗/桌面/手机、关键状态、弹窗取消及真实 HTTP/CSRF 错误回弹，不在共享预览执行真实资金、上游或通知动作。全量 Pest、PHPStan、Pint 与差异检查通过后自动提交，截图入 `docs/screenshots` 并在实施记录注明实际证据和未验证范围。
