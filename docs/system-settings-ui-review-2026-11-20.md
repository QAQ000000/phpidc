## 改进

- 按站点、支付财务、通知、账户认证、连接自动化分为五组侧导航；保留全部 `?tab=` 深链，小屏用带分组的下拉切换。

- 桌面统一标签列和控件宽度，长文本独占输入行；小屏改为标签在上。输入有明确焦点，控件支持键盘操作。
- 布尔配置使用有启停文字的原生 checkbox 开关，保留 hidden `0` 与 checked `1` 提交语义。
- 保存和原生重置集中在粘性底栏；长表单滚动时操作区保持可见。测试按钮位于独立区域和独立 POST 表单，保存不触发测试。
- 本页独立样式支持浅色/暗色和减少动效偏好，不改其他后台页面样式。没有增加构建依赖。

保留原字段名、Action、路由、CSRF、分域权限、可选 255 字备注和密钥留空保留规则。只读角色不出现保存或测试表单；秘密输入始终为空，只显示配置状态。没有迁移、真实配置改写或外部通知/供应商调用。
