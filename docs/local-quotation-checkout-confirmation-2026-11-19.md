## 行为与价格口径

商品和配置项的 `local_prices` 已由目录同步保存，但此前 `/console/products/{id}/quote` 仍读取供应商账户、库存和总价。本次该入口只读本地快照，返回周期价、开通费、币种、`estimate=true` 和五分钟有效的加密报价凭证，不访问供应商，也不创建账单或改变资金。

`QuoteLocalProductAction` 按本地售价汇总商品及已解析的配置。类型 1–19 沿用现有选项映射；普通数量按所处分段单价乘全部数量，15–19 类型按累进段计费；开通费单独累计，数量选项只收所处段的一次开通费，关闭开关同时去除周期和开通费用。金额运算仅使用 Money。依赖、数量范围和步长继续由现有 Resolver 验证；缺价格或未知规则明确拒绝，不猜测为零。同步仅额外保留已有 JSON 中的 `qty_stage` 元数据，不改表结构。

本地预估保留已同步售价，不实时套用供应商账户折扣；账户折扣、同步间价格变化、汇总舍入差异可能使提交核验结果不同。界面明确预估含商品周期价和开通费，优惠券在创建账单时计算。现有同步入口及调度方式保持；本轮没有开启后台 scheduler 或队列。

## 提交与确认

`/checkout` 继续实时验证主机名和密码规则、账户货币、商品停售/库存、配置总价及开通费。网络仍在资金事务外。输入金额不能作为售价权威。

- 本地报价凭证绑定客户、商品、上游映射、计费周期和计价配置，以及已展示的周期价/开通费/币种；不含密码或自定义交付字段。
- 凭证有效且实时金额一致时，继续原资金事务生成账单；创建后金额固定，付款时不重新报价。
- 缺凭证或任一价格分量改变，返回 HTTP 409 和新的核验报价。在此之前没有账单、钱包冻结、优惠券占用或任务；界面要求再次点击“确认新价格并创建账单”。不会自动重提。
- 确认提交仍实时核验；如再次变价，再次确认。凭证篡改、过期、跨客户/商品/周期/配置或映射变化返回 422，且不会请求供应商。
- 原购买请求键与加密 caller intent 保持；报价凭证不进入持久幂等身份。已创建请求优先返回原账单，即使凭证过期、当前价格改变或商品已下架，也不会重复扣款或重建任务。

前端保留一个在途预估和一个最新候选；配置改变立即清除旧凭证，旧响应不会覆盖新选择。提交期间固定表单，网络结果未知时保留购买请求键供显式重试。无 JavaScript 仍可通过原表单报价和返回的 409 确认页完成流程；密码和自定义字段在该确认页须重新填写。脚本预估请求只传 CSRF、周期及计价配置；无 JS 表单可能携带其他输入，预估控制器会直接丢弃，不转发到上游、不记录或回填。
