日期：2026-11-20。基线：`3075e20`。页面合同见 `customer-console-ui-contract-2026-11-20.md`。

## 交付范围

客户页从顶部横向菜单改为一套左侧导航：总览、服务、选购入口，以及可折叠的财务、账户和帮助分类。详情自动归属原入口；没有页内分类侧栏、重复横向主菜单或手机分类下拉。后台的 6 分类 / 30 入口保持原样。

公共结构使用 `x-console.page-header`、`card`、`badge`、独立 `customer-console.css/js`。原生表单、语义表格、状态文字、金额、空状态和错误反馈统一；表格在自身可聚焦容器内滚动。没有引入 UI 框架、构建链或通用动作/表格引擎。

## 请求与显示边界

本批没有修改 Controller、Action、数据库结构或旧测试。金融计算、充值/提现上下限、钱包授权、支付网关历史商户快照、续费恢复、生命周期条件及本人归属继续由原实现执行。

服务密码和卡密只在原本允许的本人 Active 详情中显示，列表/总览不增加秘密字段；历史下单资料仍从原加密订单白名单投影。第三方标识、密钥、实名明文和验证码不回填。机器/电源/监控仍需明确 POST 读取；普通 GET 不自动请求供应商或支付接口。

服务操作失败后，仅展开本实例对应动作，保留合法 ULID 和非秘密输入；钱包授权和确认框重新由客户勾选。非法数组回填不会令模板 500。普通提交不增加必填原因；终止、实名、资金等原有明确确认继续保留。

手机使用同一导航抽屉：支持关闭按钮、遮罩、Escape、Tab 焦点循环和关闭回到菜单按钮，打开时背景不可交互；桌面侧栏获得焦点后缩至手机时，焦点转移到可见菜单按钮。无脚本时菜单仍可使用。深色按系统偏好启用，并适配旧监控图表坐标文字。
