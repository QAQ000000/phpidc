## 业务与请求边界

本批未修改 Controller、Action、数据库、枚举、旧测试断言或 Specs；没有新增迁移。公开目录和普通 GET 继续使用本地同步事实，列表不访问上游、支付、通知或认证服务。隐藏商品 / 分类与错误归属路径仍拒绝访问；售罄、无周期、未支持能力及暂停新试用的既有边界保持。

固定卡品售价与经典商品同步参考基础价分别说明，不把基础价写成含全部配置的最终价。选配继续先用本地价格估算，提交时实时核对上游价格和库存，价格变化后等待客户明确确认；未建单前不改钱包或优惠券事实。

原 POST、CSRF、`request_id`、报价 token、周期、配置 ID、自定义字段、优惠券与钱包 / 网关字段保留。主机名与开通密码继续按原产品规则生成或校验；报价更新不覆盖客户已修改的主机名，密码不从历史输入回填。私密自定义字段不进入配置摘要；非活动 type20 分支不进入摘要、提交或计价。
