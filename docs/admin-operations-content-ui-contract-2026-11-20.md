## 范围与信息层级

翻新 `/admin/coupons`、`/admin/affiliates`、`/admin/payouts`、`/admin/support`、`/admin/notifications`、`/admin/downloads` 和 `/admin/content`。保持六个全局左侧分类、三十个业务入口及其权限归属；不新增页内分类侧栏或主分类 Tab。页面以说明与操作、实际支持的筛选、紧凑表格和分页组织。规则与佣金、模板与日志、文章与栏目及商品展示在同一页面按信息卡分区。

创建、编辑、定向发券和转钱包审核收进原生对话框。工单列表进入选中工单后显示会话详情，回复/关闭/重开沿用已有动作。旧记录参数 `edit`、`article`、`category`、`product`、原分页参数及全部 POST 路径继续可用；错误记录不回退到其他记录。仅在选择当前记录时展示复杂详情。

## 表单、权限与数据

所有表单保留原字段、CSRF、Controller/Action、Gate 和业务不变量。普通备注继续可选，转钱包审核保留确认与驳回理由要求；不新增真实出款、通知测试或同步行为。只读角色不出现管理表单，已发布文章的编辑仍要求发布权限，固定栏目和类型不能在 UI 中解锁。

同页多表单使用固定白名单 `_admin_form` 标记区分错误来源。验证失败只重开对应对话框并恢复其非秘密输入、记录 ID、开关与选择；其他表单不混用旧输入。既有全局 `dontFlash(code)` 规则保留，优惠券创建/发放失败须重新输入券码，编辑时显示原已保存券码；页面明确提示，不为券码放开验证码/授权码的闪存保护。上传文件不能自动回填，错误后提示重新选择。既有不带该标记的直接 POST 错误仍有页面错误反馈，不破坏接口兼容。字段值和用户文本使用 Blade 转义，通知日志继续只显示允许的错误分类，不能回显收件人、原始供应商异常或密钥。CMS 三表单备注输入限制为 255 字符以匹配审计列，后端原有接口校验不在本批扩大调整。

GET 及开关弹窗不调用上游、支付或通知，不增加业务写入。保留佣金转钱包原应收核验/预算与安全提示，不借视觉改版放行未知应收。金额使用既有定点字符串，不在模板重算。筛选只呈现当前查询已支持的字段，分页保留有效条件和其他列表页码。

## 视觉与交互

复用共享颜色、13px 基础字号、8px 卡片圆角和紧凑表格。状态用文字加徽章；金额和操作右对齐。空列表有表头与说明。弹窗有标题、关闭和取消按钮，支持 Escape、键盘焦点与触发点返回；小屏内滚动，不嵌套弹窗。长标题、编号、正文和哈希局部换行或滚动，文档不横向溢出。

顺带调整 A 批三项展示：移除首页重复的“业务概况”标题；手机账单前三列完整显示金额（创建时间仍可局部横滚）；未结支付异常/失败任务大于零显示红色，待回复工单大于零显示琥珀色，零值沿用常规颜色。统计、查询、权限与金额口径保持。
