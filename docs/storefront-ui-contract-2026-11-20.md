# 商城选购页面合同

日期：2026-11-20。基线：`c94665b`。本批整理公共站点布局、商城分类列表、商品详情及客户选配页面，复用现有 Blade、报价与购买链路；不新增迁移，不改金额、准入、库存、身份或支付规则。公共 CMS 与 SEO/GEO 响应继续兼容。

## 1. 页面结构与信息层级

公共页面使用统一品牌页头、主导航、正文与页脚。主导航保留商城、新闻、帮助、客服及匿名登录/已登录客户中心入口。商城分类是商品内容的筛选入口，不再增加一套站点侧栏。品牌、公告、客服、版权和备案沿用站点展示配置；不在模板复制配置默认值或密钥。

| 页面 | 结构与操作 | 保留边界 |
| --- | --- | --- |
| `/store` 与 `/store/{category}` | 页头、可识别的当前分类、商品卡片与分页 | 仅既有公开分类/商品；隐藏及错误分类路径仍 404，不把无商品误写成售罄 |
| `/store/{category}/{product}` | 面包屑、商品描述及准入提示、周期/价格/库存卡与原购买入口 | 固定价格和同步参考价明确区分；无周期、售罄、未支持能力、匿名购买各分支保留 |
| `/console/products/{product}/configure` | 使用客户控制台原全局左导航；一个购买 form，桌面左侧选配、右侧粘性摘要；手机按正文顺序堆叠 | 不新增选配侧栏或重复分类菜单；原配置联动、报价确认、幂等与提交字段保留 |
| 首页、新闻/帮助列表与文章 | 继续使用统一公共壳及兼容样式 | 正文清洗、发布可见性、历史 slug 跳转和 Markdown 导出保持；文章/CMS 静态页不新增脚本 |

商品卡只显示已有安全的目录事实及本地详情链接，不额外展示上游凭据、内部成本或交付秘密。未知价格/库存不画成零元或有货；远端参考信息不能伪装成实时结果。详情说明与表单按用途分区，金额和币种保持同组，长商品名/链接/描述自然换行。

## 2. 选配与购买交互

选配页保留单一购买 form，避免两个表单复制同一组选项或把摘要内的支付按钮移出原表单。左侧依次放周期、活动配置组、主机名/密码与允许的自定义字段；右侧展示本地估算、开通费、优惠与钱包/支付选择及提交提示。确有已实现字段才展示，不新增域名绑定、特殊模块或试用能力。

原字段名、`request_id`、本地报价 token、确认 token、配置组/子项 ID、自定义字段及联动节点属性保持；非活动 type20 分支仍不计价、不提交。主机名与开通密码继续由现有产品配置自动生成或按原 custom 条件要求输入，密码不从 old input 回填。前端只调整布局与既有联动挂载点，不使用浮点重新计算历史金额或替代服务端校验。

商品详情的本地直购继续原 `/checkout` POST、CSRF、产品/周期/优惠券/钱包/网关及幂等字段；classic 商品继续跳转原完整选配入口。钱包是否默认勾选、必填密码/主机名的条件及各渠道开放状态服从现有页面与后端合同。原价格变更确认必须保留：本地估算仅供选择，提交时核对上游价格/库存，变化时先确认再建单；不得用 UI 调整自动代为确认、重建请求或跳过准入。

普通列表与详情 GET 只读本地目录和同步快照，不增加供应商、支付、短信/邮件或 KYC 请求。显式报价、提交及现有必要初始化仍走原接口和授权，不在公共壳或分页脚本中轮询/预取远端。

## 3. SEO/GEO 与公开可见性

公共壳保留 title、description、可选 keywords、canonical、Open Graph、原 noindex 分支及产品/文章的 Markdown alternate 链接。配置展示值和 SEO 文本继续转义，正文继续使用现有清洗投影，不能把原始 HTML 或脚本当组件渲染。

`.md` 后缀与 `Accept: text/markdown` 协商继续返回原文本内容、Content-Type、Vary、nosniff 和 canonical Link，不能套入 HTML 壳、导航、CSS 或新脚本。canonical 保持原无查询的规范路径，搜索/分页按现有 noindex 规则；`sitemap.xml` 与 `llms.txt` 不改收录范围。隐藏分类/商品、未发布/未来文章和错误分类归属在 HTML、Markdown 及索引中继续不可见。

公共壳样式外置为 `/css/storefront.css`，保留 CMS 既有 class 的兼容；公共文章及 CMS 静态页保持无脚本。允许的页面交互仅使用本地现有资源；不新增 CDN、统计、第三方字体或后台网络请求。

## 4. 分页与响应式

分页使用轻量 `public.pagination`：`nav aria-label="分页"`，显示前页、当前/总页与后页，禁用项有明确语义。沿用原 paginator 及查询参数、独立 page 参数名称，不手工拼接丢失分类/搜索条件，不生成撑破页面的默认大 SVG。

桌面 1440×1000 检查卡片、分类、单 form 双列选配与右侧粘性摘要；手机 390×844 按页头、配置、摘要顺序堆叠，操作可触达，长表格只在本身区域滚动，文档不横向溢出。键盘焦点可见，输入关联标签，错误保持可见的 alert；价格、库存与禁止购买提示同时使用文字表达，不仅依赖颜色。

## 5. 验收范围

| 验收面 | 必须覆盖 |
| --- | --- |
| 公共壳 | 配置品牌与公告、匿名登录/已登录客户中心、原新闻/帮助/客服/页脚入口，静态 CMS 无脚本 |
| SEO/GEO | meta/canonical/noindex/alternate 保留且转义，Markdown 协商不混入 HTML 壳，隐藏路径仍 404 |
| 目录与详情 | 分类/分页语义、空态、价格/库存/准入提示及原购买分支，GET 无远程 I/O |
| 选配 | 单 form、原 ID/字段/token、type20 活动分支、自动主机名/密码、本地估算与实时确认流程兼容 |
| 视觉 | 桌面/手机、长名称/描述与本地错误，无重复导航、失效按钮或文档溢出 |

验证使用隔离 SQLite、模拟 HTTP 与原测试；不改旧断言、不迁移当前预览库、不进行真实购买/支付/供应商变更/通知发送。公共壳、目录与选配各自添加有意义回归，避免为样式快照堆砌后端规则测试；完整验收结果另写实施记录。
