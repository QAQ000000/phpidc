# U1 对象工作台与来源返回：实施记录

日期：2026-11-20。起点 `e400fd2`；合同见 [U1 页面与来源协议](admin-workspace-u1-contract-2026-11-20.md)，参考 [旧后台 UI 与层级分析](legacy-admin-ui-hierarchy-analysis-2026-11-20.md)。

## 已交付

客户、实例、账单和显式机器菜单使用共用 `x-admin.workspace-header`，集中显示对象名称、编号、中文状态、返回直接来源及原有操作。390px 下操作按钮两列排列；保留六组、31 个全局左侧入口，详情仍从列表／搜索／关联链接进入，不新增内部侧栏或模块 Tab。

`AdminWorkspaceNavigation` 以固定本地类型重建 URL。客户列表、经典服务列表与账单列表进入详情时保存白名单筛选及页码；关联对象进入下一工作台时替换来源，保留原对象的明细页码与区块。没有递归导航历史、任意 `return_url` 或全局会话位置键。

客户管理、钱包调整、线下收款、退款、实例同步／重试／机器菜单及命令保持上下文。经典状态操作与换绑的旧详情在带有效来源时保持当前实例与固定操作锚点，无来源旧入口保持原成功／失败目标。验证失败仍按原规则回填非秘密输入；机器失败不写 old-input，线下凭证编号与加密说明不回填。

三个详情的独立分页携带已过滤来源；账单既有平铺列表筛选保持兼容。来源按当前管理员的模块／区块权限裁剪，不查询来源对象、不解密凭据、不进入业务意图或资金幂等参数。VNC 签名协议保持。

- 基线：Pest **3159 passed / 27784 assertions**、PHPStan **0 errors**、Pint **PASS**。
- 新增 32 项导航回归：六类来源、恶意／数组／无效来源、分域权限、单层来源、列表还原、跨工作台跳转、三类独立分页、资料成功／失败、线下款隐私、同步失败、旧状态操作／换绑失败。旧 C4 只更新两类已改变的完整链接期望，保留每个实例入口数量及所有业务断言。
- 完成门禁：见本文件末尾 GATES。
- Chromium：1440×1000／390×844 × 浅／深色 × 五种对象／状态，**20 组布局通过**；无页面横向溢出，来源返回与状态可见，手机按钮两列，单一主侧栏，未出现秘密投影。
- **14 项实际交互检查通过**：列表筛选页码返回、客户→实例→账单、独立分页、点击返回、真实 HTTP/CSRF 验证失败与弹窗恢复、机器菜单往返、旧生命周期表单失败保持、只读角色来源裁剪及页面 JS 错误检查。
- 浏览器静态头像 `ui-avatars.com` 使用合成 SVG 替身；业务页面与本机 mock 之外未发起外部请求。截图见 [验收目录](screenshots/admin-workspace-u1-2026-11-20/README.md)，包含六张代表图、检查明细和 SHA-256。

浏览器环境使用全新临时 SQLite、storage、密钥、会话和 loopback 魔方模拟接口；未使用共享预览库，也未启动队列消费者。机器菜单读取因重试浏览器脚本执行两次，产生两条真实管理员读取审计；mock 请求仅登录一次、`/host/header` 两次，**没有 `/provision/default` 或其他供应商变更**。资金流水、线下凭证、任务队列、失败队列、通知事件／日志均为零；夹具已有履约任务只用于展示。

原预览仅检查已有项目 HTTP 进程和 `/up`、`/admin/login`、`/login`，均为 200。本批无需迁移、赋权或队列重启；不将隔离验收写成真实客户／支付／供应商业务验收。
