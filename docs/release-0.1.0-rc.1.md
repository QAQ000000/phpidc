## 本轮安装与版本变更

- 用可操作安装向导替换占位入口；bootstrap 凭据只在服务器配置。已存在业务表没有本次进度记录时拒绝接管。
- 初始管理员只授现有 access-manager，使用已有表与审计机制；未新增 schema、未修改冻结 DTO/接口、未修改业务不变量。
- 新增离线 `app:reencrypt-secrets`，包括嵌套任务/订单密文与卡密 HMAC。错 APP_KEY 在新安装站点启动时即失败。安装状态/换钥 journal 均为部署私有文件。
- 新增部署手册、Nginx/systemd 模板、独立安装验收脚本；不自动迁移业务库或启动正式服务。
- 修正 `.env.example` 中未被队列配置读取的 `QUEUE_RETRY_AFTER`，改为真实的 `REDIS_QUEUE_RETRY_AFTER=240`，符合 INV-Q1。
- 各模块说明中的历史 Gate 数字保留为当时阶段证据；**初始收口状态以此历史矩阵为索引；当前状态见上方后续索引**，不把历史 TODO 一律解释为今天未实现。
