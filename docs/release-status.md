## 应收容量与竞争证据

B3 新版脚本已验证：同一 10000 根/100000 证据夹具的 20 个普通新请求复用完整证明，准入层 P95 **3.50 ms**、历史证据 SQL 为 0；有效期最多从原扫描开始 600 秒，命中不续期。清偿/冲正/人工复核及独立审计保持完整核验；合法版本变化立即失效。五次完整核验 53.04–60.39 秒，真实冲正竞争和原请求清偿后恢复通过，细节及已批准 SQL 篡改检测窗口见 [第三批记录](architecture-third-batch-2026-11-19.md)。该准入层数据不等于 HTTP 时延。
