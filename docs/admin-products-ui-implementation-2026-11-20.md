# 后台公共组件与经典商品列表样板实施记录

日期：2026-11-20。基线：`5c43836`。页面合同见 `admin-ui-page-contract-2026-11-20.md`。

## 交付结果

`/admin/upstreams` 保持现有“上游商品与连接”入口，使用单一 Filament 全局左栏，保留 6 个可折叠分类和 30 个入口。页面以经典魔方商品列表为主体，连接管理和商品导入放入页头对话框；无内部分类侧栏或手机端分类下拉。

- 公共组件：卡片、GET 筛选条、语义表格、状态徽章、原生对话框、分页栏，共 6 个 Blade 组件。样式限定在 `.admin-ui`，支持浅色、暗色、焦点和窄屏。危险操作确认待对应页面真正需要时采用，本批普通保存和同步不增加确认或必填备注。
- 列表：关键词匹配名称或数字本地 ID/PID，连接与本地显示状态可组合筛选；按 ID 倒序，每页 20 条。分页保留有效筛选，重置回第一页。
- 行信息：名称/本地 ID、连接/PID、显示或隐藏、已同步库存、币种/周期基础价、配置组数量、更新时间/目录版本和操作。价格不取试用低价，不用浮点，不把基础价冒充最终配置价；更新时间不称最后同步时间。
- 详情：`?product=ID` 进入单件商品配置与未来续费边界，原同步和边界 POST 保留。返回列表保留筛选及页码；只有原公开目录可访问的商品显示客户配置入口。
- 连接：经典与 Sub2API 的原字段、权限和 POST 保留。密钥不回显、失败不回闪；只有提交的表单恢复非秘密字段，其他连接保持原值。Sub2API 已有地址继续只读。
- 导入目录：原 `/admin/upstreams/catalog` POST 进入同一面板壳且保持商品菜单高亮；仅投影可见组名、商品 ID/名称到 Livewire 状态，不把上游目录任意字段带入浏览器。

## 查询与错误恢复

列表只读取裁剪后的商品字段与配置组计数，不预载所有商品的配置树。只有当前详情加载选项组/子项；列表、筛选、分页和详情 GET 均不请求上游。非法筛选返回 422，非法或非经典商品详情返回 404，不回退到其他记录。

连接与导入失败后自动打开原对话框，在框内显示具体错误并恢复非秘密输入；非法数组输入安全回退，不造成页面 500。搜索字符串 `0` 保留有效筛选语义。

目录文档仅支持 POST，原流程从该文档导入失败时会默认回跳同一路径，随后 GET 返回 404。本批将导入校验异常统一返回商品页，并用现有导入弹窗恢复字段及错误，不新增目录 GET 或重复读取上游。
